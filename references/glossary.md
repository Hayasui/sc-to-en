# 术语对照表（Glossary）

跨文档、跨会话的术语一致性。**同一个概念，中英各用固定说法**，避免同一份文档里一会儿 `baseline game` 一会儿 `reference game`。

## 研究概念

| 中文 | 英文 | 说明 |
|------|------|------|
| 基准游戏 | **baseline game** | 玩家选的"最像今天这款"的游戏，用于对照打分 |
| 试玩游戏 / 今天这款 | **today's game** | 玩家本次试玩的游戏 |
| 尖叫度得分 | **"wow" score** | 试玩满意度 − 基准满意度（内部术语，不进玩家题干） |
| 研究问题 | **RQ (research question)** | 内部编号 RQ1-RQ4 |
| 研究假设 | **hypothesis** | 内部参考 |
| 画像分层 | **profile segmentation** | 背景题的用途（内部） |
| 甄别问卷 | **screener** | 资格核验问卷 |
| 访谈大纲 | **interview guide** | |
| 无人主持测试 | **Unmoderated Test** | |
| 出声思考 | **Think-Out-Loud** | 边玩边说 |

## 使用规则

1. **同一概念固定一种英文说法**，全文档统一。改的时候全局替换。
2. **内部术语（flow、distinguishability、"wow" score 等）只出现在内部参考**，绝不进玩家可见的题干/选项。
3. 新项目若引入新概念，**在这里补一行**，避免下次又要重新决定。
