# 交付前检查清单

英文版交付给用户之前，逐项过一遍。`lint_usertesting.py` 能自动查的标注了 🤖，其余需人工确认。

## A. 平台限制

- [ ] 🤖 **Instruction text ≤ 1000 字符**
- [ ] 🤖 **Navigation task instructions ≤ 1000 字符**
- [ ] 🤖 没有 `please specify` / `请说明` / `please name it` / `请填写名字` 这类平台不允许的自填提示
- [ ] 🤖 所有 Rating scale / Matrix 题都有 Scale Labels；NPS 题若写标签，低端必须是 **0**（NPS 固定 0-10）
- [ ] 端点措辞照 `survey-wording.md` 取（唯一出处），不临场另写；新增端点先改那份表
- [ ] 端点语义贴题（满意度用 satisfied 系、可能性用 play / likely 系、同意度用 agree 系），不套用同一组
- [ ] 两份英文稿的端点一致（2026-09-14 分叉过：无人版改了 `Very dissatisfied`、有人版还留着 `Very unsatisfied`）
- [ ] 没有依赖"前一题答案动态生成选项"的设计（平台做不到）
- [ ] 需要玩家记住前文选择的地方，题干里有提示（"请记住你选的这款"）
- [ ] 题干去掉加粗后依然读得通

## B. 英文本地化

- [ ] 🤖 没有残留汉字
- [ ] 🤖 没有残留中文标点（`，。；：、（）《》`等）
- [ ] 章节序号已改为英文（`一、` → `1.`）
- [ ] 括号里的中文说明已改英文（`(内部定稿)` → `(the Chinese-language draft)`）
- [ ] Question Page 标题用 Title Case
- [ ] 没有中式直译（读一遍，像不像母语者写的）
- [ ] 没有俚语（`gonna` / `awesome` / `no-brainer` 等）
- [ ] 专有名词保持原文（游戏名、平台名、题型名）
- [ ] 玩家可见部分没有专业术语（`flow` / `cognitive load` / `differentiator` 等）

## C. 中英对齐

- [ ] 🤖 中英题号数量一致
- [ ] 🤖 每题题型一致
- [ ] 🤖 每题选项数量一致
- [ ] 🤖 量表端点一致
- [ ] 英文版的语义改动已回写中文版
- [ ] 中文版的过时表述已更新（如"英文版另行产出"→"见 xxx_EN.md"）

## D. 结构完整性（新）

- [ ] 🤖 题号连续、无重复（抓"批量替换误删标题行"）
- [ ] 🤖 Task A 的 Instruction + Navigation 区块齐全（**仅访谈大纲适用**；甄别问卷无 Task 结构，脚本自动跳过）
- [ ] 🤖 Task B 的 Question Page 连续无缺失
- [ ] 术语与 `glossary.md` 一致（同一概念不出现两种英文说法）

## E. 只改该改的

- [ ] 只本地化了**玩家可见部分**
- [ ] 内部备注 / 研究落点 / 附录 RQ / 主持人提醒**保持原样**
- [ ] 没有误删任何题的标题行、内部备注（改动量大时尤其要查）

## F. 汇报

- [ ] 给出了**改动清单**（改了哪些位置）
- [ ] 给出了**理由**（为什么改，尤其"中式英文 → 地道表达"处）
- [ ] 给出了**验证结果**（lint 通过情况、中英对齐情况）

## 常见事故（都是实际发生过的）

| 事故 | 预防 |
|------|------|
| 批量替换时误删了下一题的标题行 | 以单题为单位替换，锚点不要跨题；跑 lint 的题号连续性检查兜底 |
| 润色时把 `odd` 改成了 `oddly`（引入语法错误） | 改完通读一遍，重点查形容词/副词 |
| 英文版润色完，中文版没跟上，两边漂移 | 改完英文版立即检查中文版是否需要同步 |
| 内部备注被一起"润色"了 | 改之前先分清玩家可见 vs 内部参考 |
| 游戏清单删了一款，另一处清单没删 | 清单类内容要全局搜，两处（清单题 + 基准题）都查 |
| 同一个概念前后用了两种英文说法 | 查 `glossary.md`，固定一种并全局统一 |
| lint 跑不起来、或跑完读不到输出（PowerShell 传中文路径会偶发乱码，`*>` 重定向写的是 UTF-16，Read 读不出来） | 在**纯 ASCII 目录**放一个壳子脚本，把目标路径与 `--sc` 写进源码，再让脚本自己把报告写成 UTF-8 文件供 Read（项目目录名是中文时每次都适用） |
